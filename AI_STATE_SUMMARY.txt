web-scheduler app quick context (app.js)

PRIMARY STATE OBJECT (`state`)
- currentUserId: string|null             — employee.id of signed-in user
- currentUserDisplayName: string|null    — from Entra ID displayName
- currentUserTitle: string|null          — from Entra ID jobTitle
- currentUserEmail: string|null          — from Entra ID mail/UPN
- currentUserEntraId: string|null        — Azure AD object ID
- loginRole: "employee" | "supervisor"
- currentRole: "employee" | "supervisor"
- isAuthenticated: boolean
- currentView: "day" | "week" | "month"
- currentDate: ISO date string (YYYY-MM-DD)
- scheduleStatus: "draft" | "published"
- units: Unit[]
- employees: Employee[]
- trades: Trade[]
- overtimePosts: OvertimePost[]
- notifications: Notification[]
- auditLog: AuditEntry[]
- importPreview: EmployeeImportPreview|null
- unitImportPreview: UnitImportPreview|null
- assignments: Record<date, Record<unitId, Employee[]>>
- activeSurface: "schedule" | "admin"
- activeAdminTab: string (default "employees")
- employeeFilter: { search, shift, status, sort }
- selectedEmployeeId: string|null
- employeeDraft: Employee|null
- persistence:
  - backend: "browser-memory" | "local-storage" | "supabase" | "supabase-fallback"
  - status: string
  - hasRemote: boolean
  - isSaving: boolean
  - lastSavedAt: ISO timestamp|null
  - level: "ok" | "warning" | "danger" (set dynamically)

COMMON ENTITY SHAPES
- Employee:
  { id, entraId?, name, shift (A|B|C|null), title, certs[], email, isSupervisor, status }
  NOTE: `pin` removed — auth is now Entra ID only
- Unit:
  { id, name, type, minStaff, requiredCerts[], shift, visible }
- Trade:
  { id, status, employeeId, partnerId, date, notes, type, createdBy }
- OvertimePost:
  { id, status, unitId, date, qualification, reportTime, applicants[], approvedEmployeeId? }

IMPORTANT TOP-LEVEL CONSTANTS
- baseDate, ROTATION_BASE_DATE, rotationPattern, LOCAL_STORAGE_KEY, REMOTE_STATE_ID
- SUPERVISOR_TITLES: ["Batt. Chief", "Div. Chief", "Captain", "Lieutenant", "MOF"]
- UNIT_POSITION_REQUIREMENTS: Record<unitType, {role, label, eligibleTitles[]}[]>
  Types: Batt, Ladder, Medic, MOF, Engine, Rescue, Tender, Brush
  Positions listed most-restrictive-first for greedy matching in checkPositionStaffing()

- unitTypes: ["Engine","Ladder","Medic","Batt","MOF","Tender","Brush","Rescue"]
- employeeTitleOptions: ["Batt. Chief","Div. Chief","Captain","Lieutenant","Engineer","MOF","FF/EMTP","FF/EMT"]
- msalInstance: PublicClientApplication | null
- GRAPH_SCOPES: ["User.Read","User.ReadBasic.All"]

AUTH FLOW (Entra ID / MSAL)
- initMsal(): initializes MSAL; surfaces load/config errors to dom["auth-message"] instead of failing silently
  - silent token acquisition is in a nested try/catch so init errors are not swallowed
- handleMsalLogin(): loginPopup (redirectUri = origin + "/blank.html") → acquireTokenSilent → setAuthFromToken → render
  - Uses blank.html as popup redirect target — avoids re-running the full app inside the popup
  - If msalInstance is null, shows toast + error text instead of silently returning
  - Error toast includes errorCode for easier diagnosis
- handleMsalSignOut(): clears state, calls logoutPopup
- setAuthFromToken(accessToken, account): fetchGraphProfile → syncEmployeeFromEntraProfile → set state
- fetchGraphProfile(token): GET /v1.0/me?$select=id,displayName,mail,userPrincipalName,jobTitle,department
- syncEmployeeFromEntraProfile({entraId, name, email, jobTitle}): match by entraId/email; update or create
- defaultCertsForTitle(title): maps D7FR title → certs[]
- MSAL config: APP_CONFIG.msalConfig (clientId + authority in config.js)
- blank.html: dedicated empty page at repo root; MUST be registered in Azure App Registration →
  Authentication → Single-page application as: https://schedule.d7fr.org/blank.html

SEED / INIT FLOW (current behavior)
- DOMContentLoaded -> hydrateAppState() -> initMsal() -> initializeControls() -> render()
- seedDefaultState() is EMPTY-DATA only (employees=[], units=[], etc.)

PERSISTENCE FLOW
- serializableState(): units, employees, trades, overtimePosts, notifications,
  auditLog, assignments, scheduleStatus, employeeFilter, activeSurface, activeAdminTab
- saveLocalState()/loadLocalState() use LOCAL_STORAGE_KEY
- optional remote via Supabase REST (loadRemoteState/saveRemoteState)
- applyPersistedState(data):
  - migrateShiftNames(data)
  - migrateEmployeeTitles(data)   ← maps legacy title strings to current D7FR titles
  - migratePersistedUnitTypes(data.units)
  - then assigns state collections and UI prefs

STAFFING ALERTS
- getStaffingAlerts(date): uses UNIT_POSITION_REQUIREMENTS when available
- checkPositionStaffing(unit, people, positions): greedy match; unfilled positions → danger alert
- Falls back to minStaff + requiredCerts for any unit type not in UNIT_POSITION_REQUIREMENTS
