## The core model added this session

**Time blocks.** `Assignment.start_minute` / `end_minute` = minutes from the UNIT's
tour start, so a full tour is `0..unit.tour_minutes` and nothing wraps midnight.
Transport to the SPA is underscore fields on the person object alongside
`_pay`/`_payFor`: `_start`, `_end`, `_off`, `_offNote`, `_noFill`. A full tour sends
NO block fields, so old clients keep working.

**Per-unit tour shape.** `Unit.schedule_class` (`operations` | `admin`),
`tour_start_hour`, `tour_minutes`, `weekdays` (JSON, Mon=0). Admin = 0800-1800
(600 min), Mon-Thu. Nothing hard-codes 1440 any more — it asks the unit.

**Admin units are excluded** from the operations board, print sheet, staffing alerts,
and the overtime and trade boards. `visibleUnits()` splits into `operationsUnits()` /
`adminUnits()`; an "Admin" view button renders `renderAdminSchedule()`.

**Absences.** `Assignment.absence_code` (`PTO`/`SICK`/`FMLA`/`LTD`) + `absence_note` +
`absence_no_backfill`. An absence block KEEPS its hours (payroll) but COVERS NO SEAT,
so the rig reads short and an "Off this tour" roster under the seats says who and why.
`LTD` is **Light Duty** — never picked from the dropdown, derived live from the
member's light-duty date range, flagged no-backfill.

**Light duty** = `Employee.light_duty_start` / `_end` / `_note` (a date range; blank
end stays open). Blocks operations pickers with a reason, and vacates operations
seats they were ALREADY assigned to. Admin seats are unaffected — that's where they work.

**Admin platoon + qualification.** `Employee.shift` widened to 10 chars, value
`ADMIN` (in `SHIFT_CHOICES`, NOT in `ROTATION_PLATOONS` — never on duty, never forced
by the 72-hour rule). `admin` is a cert in `employeeRoles`; every `Admin` unit seat has
`cap: "admin"`. It's in `PERSON_HELD_CAPABILITIES` so a roster re-import can't strip it.

**30-minute increments.** Storage stays minutes; inputs are `step="1800"`, entry snaps
to the nearest `:00`/`:30`, durations read as `4h` / `1.5h` / `20h`.

**UI toggles.** `PAY_UI` (pay codes) and `HOURS_UI` (Split + Time off) — both off by
default, localStorage per viewer. They hide only EDITING controls; existing hours
chips, OPEN gap pickers and the off-roster always show.

## Traps already fixed — don't reintroduce
- `unique_together` on Assignment is `(employee, unit, date, start_minute)`, and the
  `_write_state` dedupe key matches. The old 3-tuple made split coverage impossible.
- Pay-code controls carry `data-pay-start`; patching by person id alone hit the wrong
  block on a split tour.
- `coverageGaps` is the OVERTIME scanner. The seat helpers are `tourGaps`/`tourCovered`.
  A duplicate top-level `function` silently wins for the whole file.
- `_write_state` prunes units missing from the client payload. Units created in the
  last `NEW_UNIT_GRACE_MINUTES` (60) are exempt, or a unit made in Django admin gets
  deleted by the next autosave from an open tab.
- `blockOf` must not default `_start` and `_end` independently — junk in one field
  produced a block nobody typed. Either unusable ⇒ whole block reads as full tour.
- An unknown absence code or platoon reads as WORKING / unassigned, never as "off".
- Global `input { width: 100% }` — size any new radio/checkbox explicitly or it grows
  as a flex item and shoves its label to the far edge.
- Board order: `byBoardOrder` falls back to ALPHABETICAL on a sortOrder tie. The
  Manage → Units ↑/↓ arrows renumber the whole list 1..N to prevent ties.
